## Ways of working

- **Branch → pull request → review → merge.** No direct commits to `main` for content changes.
- **Meaningful commit messages:** say what changed and why, e.g. `Topic 4: correct Fifth Generation dates to 1982–1992 (IPSJ, Nature 1992)`. Avoid "Update README.md" or "Add files via upload".
- **Each member commits their own work.** If someone uploads on another's behalf, the commit message says `Author: <name>, uploaded by <name>`.
- **Errors found during production** are fixed in the Markdown first (see `resource-mapping.md`).
- **Private material** (personal logs, student IDs, meeting photos/videos) stays out of this public repository.
