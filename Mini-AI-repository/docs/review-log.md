# Content Review Log

Every topic must be reviewed by a team member **who did not draft it** before its status changes to **Checked**. Record each review here (or link the pull-request review and copy the main points here, so the record is also in the submitted ZIP).

## Review checklist

For each topic, the reviewer checks:

1. **Accuracy:** are definitions, claims, examples and answers correct?
2. **Sources:** does each cited source exist, and does it actually support the sentence it is attached to?
3. **Beginner-friendliness:** is every new term defined at first use? Is anything assumed that the prerequisites don't cover?
4. **Activities:** can each activity be completed using only the information given? Do the answers match the questions?
5. **Assets:** do all images and links work in the **downloaded** copy (not just on GitHub)?
