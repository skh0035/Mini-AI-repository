## Ways of working

- **Branch → pull request → review → merge.** No direct commits to `main` for content changes.
- **Meaningful commit messages:** say what changed and why. Avoid "Update README.md" or "Add files via upload".
- **Each member commits their own work.** If someone uploads on another member's behalf, the commit message says: `Author: <name>, uploaded by <name>`.
- **Coordination:** WeChat for quick messages; decisions about content go into PR comments or `review-log.md` so there is a record.
- **Private material** (personal logs, student IDs, meeting photos/videos) stays out of this public repository.
